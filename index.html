How it works.

  1. Click Kororin in your toolbar.
  2. Pick a vibe.
  3. A new tab opens with a random repo, plus a small card telling you what you found.

Privacy, simply.

One GitHub API call per click. No accounts, no tokens, no servers, no analytics.

A small per-tab note (which mode you came from) is kept in session storage and cleared when the tab closes.
